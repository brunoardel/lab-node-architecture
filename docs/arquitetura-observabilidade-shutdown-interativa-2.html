⏱️ Trilha do Graceful Shutdown

1. Disparo de Requisição em Voo (/api/calculo)
Requisição inicia processamento pesado (duração estimada: 1.2s).
2. Sinal SIGTERM Recebido
Watchdog timer iniciado (10s tolerância). Ordem de fechamento iniciada.
3. Drenagem de Conexões (Prioridade 10)
Novas conexões rejeitadas; sockets ociosos (Keep-Alive) fechados.
4. Conclusão da Requisição em Voo
Requisição responde HTTP 200 OK sem ser interrompida.
5. Finalização de Worker Pool (Prioridade 20)
Worker Threads secundárias terminadas com sucesso. Processo sai com código 0.

AsyncLocalStorage

Módulo node:async_hooks • Observabilidade Assíncrona

Classe nativa do Node.js que fornece armazenamento de variáveis com escopo de continuidade assíncrona (análogo ao ThreadLocal em ecossistemas multi-threaded). Permite que dados de contexto (como correlationId) sejam acessados em qualquer ponto da execução assíncrona sem repassar parâmetros.

Impacto em Produção: Elimina 100% do prop-drilling de objetos req através de controllers, services e repositórios, mantendo contratos de domínio puros e facilitando rastreamento distribuído em APMs.
Exemplo de Implementação no Projeto
// src/observability/correlation-context.ts
export const correlationStorage = 
  new AsyncLocalStorage();

export function getCorrelationId(): string | undefined {
  return correlationStorage.getStore()?.correlationId;
}
